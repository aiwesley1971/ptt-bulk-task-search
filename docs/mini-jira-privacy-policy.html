Privacy Policy

Mini Jira Sidebar  ·  Last updated: September 10, 2026

Summary: This extension uses Google Sign-In only to verify that you belong to an authorized Google Group. Your Jira credentials are stored only on your device and used only to call your own Jira instance directly. No Jira, PTT, or comment/issue data is ever collected or transmitted to the developer.

1. Overview

Mini Jira Sidebar ("the Extension") is a Chrome browser extension that shows a signed-in user's assigned Jira Cloud issues in a browser side panel, and provides two-way lookup between a Jira issue and its linked task on the internal PTT system (live.pttgps.vip). Access is restricted to members of a specific Google Group. This policy describes what data the Extension accesses and how it is handled.

2. Data We Access

The Extension accesses the following data solely to provide its core functionality:

  • Google Account email address, name, and profile picture — used at sign-in to verify Google Group membership (see Section 4)
  • Jira Base URL, email, and API token — entered by the user in Settings, used only to call that Jira instance's own REST API directly from the browser
  • Jira issue, comment, attachment, and history data — fetched directly from the user's own Jira instance and displayed in the side panel
  • Optionally, PTT login credentials — entered by the user in Settings for auto-login convenience
  • Web page content from live.pttgps.vip (the "Ticket ID" / "New Ticket ID" field text), read using the user's existing login session, to power the Jira↔PTT lookup
  • Sign-in state, Jira/PTT settings, and cached issue data, stored locally via chrome.storage.local

3. Data We Do NOT Collect

The Extension does not:

  • Store, log, or retain your Google account email, Jira credentials, or Jira/PTT data on any server operated by the developer
  • Collect, transmit, or share issue, comment, attachment, or PTT data with the developer or any third party
  • Send Jira or PTT data to any server other than the user's own configured Jira instance and live.pttgps.vip
  • Track user behavior or browsing history
  • Use analytics, advertising, or telemetry services

4. Sign-In & Authorization (Google Group Check)

When you click "Sign in with Google," the Extension requests an access token via Chrome's built-in Identity API (chrome.identity) with the userinfo.email scope only — no other Google data is requested.

This token is sent to a Google Apps Script endpoint controlled by the developer, which:

  • Verifies the token directly with Google's official token-info endpoint to retrieve your email address
  • Checks whether that email address is a member of an authorized Google Group
  • Returns only an allow/deny result (and your email/name/picture for display in the extension UI) — nothing is written to a database or stored server-side

If you are not a member of the authorized group, you will be shown a link to request access. The Extension cannot be used without successful sign-in and group verification.

5. Jira Credentials & Data

Your Jira Base URL, email, and API token are stored only in this browser via chrome.storage.local and are used exclusively to call your own Jira Cloud instance's REST API directly from your browser (Basic authentication over HTTPS). They are never sent to the developer or any server other than the Jira instance you configured. You can remove them at any time from the extension's Settings page.

6. Local Data Storage

Your sign-in status (email, name, picture), Jira/PTT settings, and cached issue data are saved locally on your device using Chrome's built-in storage API (chrome.storage.local) so they persist across browser sessions. This data never leaves your device except for the direct API calls described above, and can be cleared at any time via the extension's Settings or by removing the extension.

7. Permissions Explanation

  • identity — Required to sign in with Google and obtain an access token for group-membership verification
  • storage — Required to save and restore sign-in state, Jira/PTT settings, and cached data locally on your device
  • sidePanel — Required to render the extension's UI in Chrome's side panel
  • scripting — Required to read the "Ticket ID" field on the active PTT task page for the Jira↔PTT lookup
  • tabs / activeTab — Required to detect the active tab and open PTT pages or the side panel
  • clipboardWrite — Required for "click to copy" convenience buttons
  • host_permissions (live.pttgps.vip) — Required for PTT auto-login and reading the Ticket ID field using your existing authenticated session
  • host_permissions (script.google.com / script.googleusercontent.com) — Required to call the authorization endpoint that verifies Google Group membership
  • Optional host permission (your Jira domain) — Requested only when you enter your Jira Base URL in Settings and click "Test Connection," so the Extension can call that specific Jira instance's API on your behalf

8. Authentication to live.pttgps.vip and Jira

For PTT, the Extension uses your existing browser session (cookies) on live.pttgps.vip, managed entirely by Chrome and the PTT platform; an optional auto-login feature can fill the login form using credentials you save locally. For Jira, the Extension authenticates directly to your Jira instance using the API token you provide — the developer never sees or receives this token.
