Privacy Policy

PTT Bulk Task Search  ·  Last updated: May 24, 2026

Summary: This extension does not collect, transmit, or share any personal data. All data stays on your device.

1. Overview

PTT Bulk Task Search ("the Extension") is a Chrome browser extension that lets users bulk-search task keys on live.pttgps.com and export results as CSV. This policy describes what data the Extension accesses and how it is handled.

2. Data We Access

The Extension accesses the following data solely to provide its core functionality:

  • Task keys entered by the user in the extension interface
  • Web page content from live.pttgps.com, retrieved using your existing login session
  • Search results, temporarily stored in Chrome's local storage (chrome.storage.local)

3. Data We Do NOT Collect

The Extension does not:

  • Collect, transmit, or share any personal data with the developer or any third party
  • Send any data to external servers other than live.pttgps.com
  • Track user behavior or browsing history
  • Use analytics, advertising, or telemetry services
  • Access data from any website other than live.pttgps.com

4. Local Data Storage

Search results are saved locally on your device using Chrome's built-in storage API (chrome.storage.local) so they persist across browser sessions. This data never leaves your device and can be cleared at any time using the Clear button within the extension.

5. Permissions Explanation

  • tabs — Required to open the search interface in a new browser tab
  • storage — Required to save and restore search results locally on your device
  • host_permissions (live.pttgps.com) — Required to fetch task data from the PTT platform using your existing authenticated session

6. Authentication

The Extension does not collect or store login credentials. It uses your existing browser session (cookies) on live.pttgps.com, which is managed entirely by Chrome and the PTT platform.
