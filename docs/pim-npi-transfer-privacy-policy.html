PIM NPI Transfer Privacy Policy

Chrome extension: PIM NPI Batch Transfer · Last updated: October 2, 2026

Summary: The extension processes product information to help authorized users perform NPI Transfer tasks in their PIM system. It does not send business data to a developer-operated server or advertising/analytics services. Search and save actions send the necessary business data to the PIM system the user is signed into.

1. Scope and purpose

This policy applies to the PIM NPI Batch Transfer Chrome extension (also referred to as PIM NPI Transfer). Its single purpose is to help authorized users validate product lists and carry out sequential NPI Transfer operations in the PIM NPI Readiness Check screen. It does not grant access to PIM or replace the system's access controls.

2. Information processed

  • Information entered, pasted or uploaded by the user: Locale, Product ID, NPI Month and Remark.
  • Relevant PIM page and request/response information needed to validate a target product and verify a save, including product identifiers, NPI status, month, remark and processing messages.
  • The active tab URL when the user clicks the extension icon, solely to determine whether to open the supported PIM panel or the extension's preview page.
  • Processing results and timestamps used to display progress and create a CSV file when requested.

Remark is free text. Any personal information the user includes in it will be processed as part of the task and may be sent to PIM when saved. Do not include personal information that is unnecessary for the business task.

3. Use and transmission

The extension uses this information only to provide its stated functionality. Search actions send query conditions to the signed-in PIM system through its existing page functions. After the user selects the save mode and confirms the change, the page sends the target product identifiers, month and remark to that PIM system. The extension checks the site's responses and displayed results to report the outcome.

The offline preview does not search PIM or save business data. Opening a PIM link from the preview navigates to that site under the user's control. Preview input is not automatically transferred to the PIM panel.

4. Authentication and permissions

The extension relies on the user's existing PIM login session, which is managed by the browser and the PIM website. It does not separately read, store or transmit passwords, cookies or authentication tokens. PIM's own requests use its normal authenticated session.

  • activeTab: provides temporary access to the current tab following an explicit click on the extension icon, to identify the supported page and open the processing panel.
  • scripting: injects the UI and automation code bundled with the extension into the supported PIM page to perform the user-requested validation and transfer task.

The extension does not monitor general browsing history or track other tabs in the background. Its own executable code is packaged with the extension; it does not download executable code from an external server. It interacts with the PIM page's existing UI, jQuery and grid objects.

5. Storage, retention and deletion

Input and results are held in the open page's memory. The extension does not persist them in extension storage or a developer-operated database. Closing or reloading that page ends the extension's in-memory task state. When the user chooses CSV export, a file is saved on the user's device; the user manages and deletes that file.

Data saved to PIM remains subject to that system's retention and deletion policies. Closing the extension, clearing browser data or uninstalling the extension does not undo a PIM save or delete downloaded CSV files. Contact your PIM administrator about records retained by that system.

6. Sharing and limited use

The developer does not receive business data through the extension. The extension does not sell data, use data for advertising, transmit it to analytics or telemetry services, or use it for creditworthiness or lending decisions. Data is used only to deliver the NPI Transfer functionality. The direct transmission to the user's PIM system described above is necessary to provide that functionality.

7. This policy website

This policy page contains no analytics scripts, advertising or input forms. It is hosted by GitHub Pages; visiting it is subject to GitHub's own privacy statement, including its handling of website request information.

8. Changes and contact

This page will be updated if the extension's data handling changes. The date above identifies the latest revision. For privacy questions, contact the developer through the privacy policy repository. Do not post credentials, confidential product information or personal data in public issues. Contact your internal PIM administrator for requests concerning PIM records.
